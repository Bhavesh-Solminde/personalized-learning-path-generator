# 🎓 Personalized Learning Path Generator

A modern web application that provides AI-powered learning recommendations based on user interests, performance, and learning style preferences. Similar to platforms like Coursera and LeetCode, but with personalized pathways.

## ✨ Features

### 🎯 Core Functionality

- **Personalized Assessment**: Interactive questionnaire to determine learning preferences
- **AI-Powered Recommendations**: Smart suggestions based on user profile and progress
- **Progress Tracking**: Visual progress charts and performance metrics
- **Course Catalog**: Comprehensive course library with filtering capabilities
- **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices
- **Dark/Light Theme**: Toggle between light and dark modes

### 🛠 Technical Features

- **Modern CSS**: Uses CSS custom properties and modern layout techniques
- **Smooth Animations**: Engaging hover effects and transitions
- **Local Storage**: Saves user preferences and progress
- **Intersection Observer**: Lazy loading and scroll animations
- **Modular JavaScript**: Clean, organized code structure

## 🚀 Technology Stack

### Frontend

- **HTML5**: Semantic markup with proper accessibility
- **CSS3**: Modern styling with custom properties and flexbox/grid
- **Vanilla JavaScript**: ES6+ features with modular architecture

### Planned Backend (Future Implementation)

- **Java Servlets**: Backend API for recommendations
- **SQL Database**: Store subjects, courses, difficulty levels, student progress
- **React Dashboard**: Advanced analytics and progress visualization

## 🎓 Learning Assessment System

The assessment evaluates:

1. **Programming Experience**: Beginner to Expert levels
2. **Interest Areas**: Web Dev, Data Science, Mobile Apps, Game Dev
3. **Time Commitment**: Weekly learning hours available
4. **Learning Style**: Visual, Reading, Hands-on, Interactive

Based on responses, the system generates personalized course recommendations.
